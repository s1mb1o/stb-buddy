REST and MCP on this device

The REST API controls physical UART and IR hardware, stores Wi-Fi and remote settings, and can replace the running firmware. It has no authentication. Use it only while the device and network are trusted.

This page is read-only: it describes operations but never invokes them. MCP uses Streamable HTTP JSON-RPC at /mcp; detailed MCP tool schemas are returned by tools/list.
