stb-buddy help

Connect the UART

Use 3.3 V TTL: AtomS3R GND ↔ STB GND, G2 TXD → STB RXD, and G1 RXD ← STB TXD. Leave 5 V disconnected while USB powers the AtomS3R.

Console and port

Click the terminal and type normally. The default is 115200 8N1. Select UART1 · baud to change the live format; reboot restores defaults. MCP and HTTP API writes appear as magenta annotations. Clear History permanently removes all retained bytes and UART-write annotations.

Files and IR

Download file… requires an STB Linux shell prompt and copies up to 2 MiB with SHA-256 verification. IR loads or saves lircd.conf and sends named keys; successful sends appear in magenta.

Wi-Fi and OTA

Hold the AtomS3R button for two seconds to start the open Buddy-<MAC> setup AP at 192.168.4.1. OTA accepts only stb_buddy.bin; verify the version, then restart separately.

Trusted network only. UART, IR, Wi-Fi and OTA APIs have no authentication, and OTA images are integrity-checked but not signed.
